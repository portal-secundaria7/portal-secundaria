# Portal web para escuela secundaria

Primera versión funcional y responsive.

## Archivos
- `index.html`: sitio público.
- `styles.css`: diseño y adaptación móvil.
- `app.js`: contenido de ejemplo e interacción.
- `admin.html`: panel administrativo de demostración.

## Próxima fase recomendada
1. Definir nombre, logo, colores y datos reales.
2. Crear backend y base de datos.
3. Autenticación segura para administradores.
4. CRUD de avisos, calendario y documentos.
5. Subida segura de PDFs.
6. Dominio, hosting y HTTPS.
7. Políticas de privacidad y protección de datos.

Los datos incluidos actualmente son ficticios.
